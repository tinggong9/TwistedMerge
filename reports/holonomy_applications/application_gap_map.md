## Required shared observation unit

The observation unit is a frozen corpus setting identified by corpus seed, adapter seed set, chart/graph condition, transition estimator, merge/pooling method, and controlled-capacity case. All rows derived from the same corpus seed or perturbation family remain in the same train/validation/test group for Application D. Image-level rows are never treated as independent linter samples.

## Evidence labels

- `natural_measured`: transitions estimated from independently fitted D4 adapters on frozen CIFAR-10 features.
- `controlled_on_real_features`: a preregistered projective layer imposed on the same frozen real features for Application C.
- `structural_control`: exact group/matrix identities with no task-performance implication.
- `invalid_quarantined`: label-derived or otherwise invalid empirical accuracy; provenance only.
- `reference_negative`: completed prior experiment used to prevent duplication, never pooled into the new estimate.

Every report and CSV must carry one of these labels. Natural and controlled rows must be summarized separately.

## Deliverable sequence

1. Commit this audit gate.
2. Implement and commit the shared-corpus configuration, manifest, integrity tests, and bounded smoke.
3. Train/save the shared corpus once and commit its non-checkpoint ledgers plus reproducible checkpoint manifest.
4. Run and commit A, then B, then C, then D, without retraining chart models.
5. Write a final assessment that distinguishes positive, negative, abstained, invalid, and inadequate-sample outcomes.

No existing manuscript file is part of this sequence.

\section{External Integration Reproducibility Appendix}
\label{app:external-integration}

This appendix records the official external-code integration attempts for the
model-merging baselines and Neural Sheaf Diffusion.  The supported claim is
limited: official integrations are documented; main comparisons remain faithful
in-repository unless official runs succeeded.  The current artifacts do not
support the claim that official external code confirms the method.

\paragraph{Blocked model-merging official baselines.}
Git Re-Basin is JAX/Flax/TFDS/W\&B-based and its MNIST MLP scripts expect
Flax/W\&B artifacts for a deeper Dense(512) architecture.  The current project
environment lacks the required JAX/Flax stack and has no nix shell available;
the saved TwistedMerge checkpoints are PyTorch one-hidden-layer MLP state
dicts.  C2M3 pins Python 3.9.19, Torch 1.13.0, Hydra, PyTorch Lightning,
TorchMetrics, and W\&B; neither uv nor Python 3.9 is available here, and the
official MLP configuration does not match the TwistedMerge checkpoint format.
Model Soups targets CLIP/ViT ImageNet soups in an old conda Python 3.6/Torch
1.7 stack, not MNIST MLP checkpoints.  Consequently, no official model-merging
baseline CSV or official comparison table was generated.

\paragraph{Faithful in-repository comparisons.}
The active comparison layer therefore remains the license-clean in-repository
surrogates: Git-ReBasin-style pairwise permutation alignment, C2M3-style
cycle-consistent permutation synchronization, and Model-Soups-style greedy and
uniform soups.  These are suitable for the paper's current faithful in-repo
comparison claims, but they are not official-code results.

\paragraph{Neural Sheaf Diffusion.}
The official Neural Sheaf Diffusion repository was run in a separate Python 3.9
PyG-compatible environment.  A tiny WebKB Texas BundleSheaf smoke run completed
with test accuracy \(0.6486\) and best validation accuracy \(0.5254\).
TwistedMerge then post-processed the official learned transport cache for
triangle cycle diagnostics.  The unweighted connection cache had 67 triangles
and mean cycle score about \(3.438\times 10^{-7}\).  The weighted cache score
near \(0.9997\) includes learned scalar edge weights and is not a pure
connection obstruction.  A cycle-regularizer attempt was not applied because
the relevant official cache is detached via \texttt{clone().detach()}.

\paragraph{Claim boundary.}
This appendix documents what was attempted, what ran, and what remains
adapter-only or future work.  It does not show that official external code
confirms TwistedMerge, beats official C2M3/Git Re-Basin/Model Soups, improves
GNNs through cycle regularization, or supports model-merging claims from NSD.
